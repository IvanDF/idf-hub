# iDF Design System

> **Palette "Lario & Volta"** — inspired by Lake Como (Lario) and Alessandro Volta.
> Type scale follows **Typefaces Details.pdf** — the canonical design reference.

This is the living style guide for the iDF Hub. Every token is defined in
`src/styles/_variables.scss` and enforced via the `<Text>` component.

## Typography

### Font Families

| Token | Font | Usage |
|---|---|---|
| `$font-family-display` | Josefin Slab 700 | Display / H1 / Small captions |
| `$font-family-primary` | Josefin Sans 400/500/600/700 | Headings H2–H6, Body, Labels |
| `$font-family-mono` | Geist Mono | Code, terminal, data |

### Text Component

Use the `<Text>` atom instead of raw `<h1>` / `<p>` / `<span>` tags:

```tsx
import Text from '@/components/atoms/text';

<Text variant="h1">Page Title</Text>
<Text variant="body">This is body copy with proper line-height and letter-spacing.</Text>
<Text variant="mono">npm run dev</Text>
<Text variant="label">BUTTON LABEL</Text>
```

Override the semantic HTML element with the `as` prop:
```tsx
<Text variant="h1" as="p">Styled like H1, semantic as P</Text>
```

### SCSS Mixins

For use in `.module.scss` files, import typography mixins:

```scss
@use '@/styles/mixins' as *;

.title {
  @include heading-h1;
}

.caption {
  @include text-small;
}
```

Or use the dynamic `heading()` mixin:

```scss
.sectionTitle {
  @include heading('h2');
}
```

### Deprecated Numeric Tokens

The old `$font-size-*` tokens (2xs through 4xl) remain available for
terminal, micro-text, and special use cases but are **not** part of the
canonical type scale. Use the semantic tokens (h1–h6, body, small, label)
for all new work.

## Design Rules

- **Typography**: Always use `<Text>` component. Never hardcode font sizes.
- **Icons**: Lucide React, 24px base, 2px stroke, rounded caps
- **Touch targets**: minimum 44×44px (WCAG AA)
- **Animations**: respect `prefers-reduced-motion`
- **Mobile-first**: design for 375px, enhance for desktop
- **Styling**: use SCSS modules first; for typography, prefer the `<Text>` component or `@include` mixins
- **Font loading**: Josefin Sans (400/500/600/700), Josefin Slab (700), Geist Mono — all via `next/font`
