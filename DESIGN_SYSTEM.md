# Design System & Tools Documentation

This portfolio uses a multi-platform design approach optimized for different project types:

### **Figma** - Web & UI Design

Used for:

- Web application interfaces and UX prototypes
- Interactive component systems
- Collaborative design handoff to development
- Figma plugins and design utilities
- Digital product design

**Projects using Figma:**

- Icon Builder (Figma Plugin)
- filteroo (design system)
- Other web-based interactive projects

### **Affinity Designer** - Print & Vector Graphics

## Gallery Viewer Features

All projects in the Research Lab with gallery images now feature:

- **Click to Zoom** - Click any image to zoom in/out (1.5x scale)
- **Keyboard Navigation** - Use ← → arrow keys to browse images
- **Thumbnail Strip** - Quick access to all images in the gallery
- **Image Counter** - Track position (current / total)
- **Mobile Responsive** - Optimized touch experience on smaller screens
- **Smooth Transitions** - Framer Motion animations for seamless browsing

## Design Philosophy

**Platform-First Approach:**

- Choose the right tool for the right job
- Figma excels at collaborative UI/UX design workflows
- Affinity Designer provides superior print and technical graphics capabilities
- Both tools maintain consistency through design tokens and shared component libraries

**Quality Focus:**

- High-fidelity mockups and prototypes
- Production-ready assets
- Version control through version history and exports
- Handoff documentation for development teams
